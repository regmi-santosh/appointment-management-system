# Toolkit templates

This folder contains YAML/MD templates for the agentic toolkit artifacts used by the VS Code agents framework.

- `toolkit/templates/agent.template.yaml` — agent manifest template
- `toolkit/templates/subagent.template.yaml` — subagent manifest template
- `toolkit/templates/rule.template.yaml` — governance rule template
- `toolkit/templates/skill.template.yaml` — skill manifest template
- `toolkit/templates/instructions.template.md` — instructions template for users
