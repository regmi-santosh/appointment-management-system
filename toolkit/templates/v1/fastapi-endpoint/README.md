FastAPI endpoint template (v1)

Placeholders:
- `{{module_name}}` — python module name (e.g., `appointments`)
- `{{router_path}}` — API path (e.g., `/appointments`)
- `{{model_name}}` — Pydantic model name (e.g., `Appointment`)

This template is intended as a vetted starter for generating simple CRUD endpoints.
Keep templates minimal and require Board approval before adding new versions.
