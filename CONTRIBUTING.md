# Contributing

Thank you for contributing! Please follow these guidelines to make the review process smooth.

- Fork the repo and create a topic branch per feature/bugfix.
- Follow the coding style in `CODE_STYLE.md`.
- Include tests for bug fixes and new features.
- Run `pre-commit` hooks locally before pushing.
- Write clear commit messages (use conventional commits).

Pull Request
- Open one logical change per PR.
- Link relevant issue(s) and provide a short description and testing steps.
- Assign reviewers and set appropriate labels.
